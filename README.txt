SBAR Shift Handover - installable app (PWA)

1. Upload this whole folder to any HTTPS host (GitHub Pages, Netlify Drop, Cloudflare Pages, Firebase Hosting).
2. Open the link on your phone:
   - Android Chrome: menu > Install app / Add to Home screen
   - iPhone Safari: Share > Add to Home Screen
3. After the first online load it works offline, and patient data is saved on the device.
